# drafts/

公众号文章草稿目录。

## 用途

- 按序号撰写的公众号原稿在这里版本控制，**不对外发布**
- 真实素材（对话截图说明、候选标题、修改痕迹）也收纳在这里，便于下一轮复用

## 命名约定

```
{序号}-{模式}.md
```

- `{序号}`：第几篇（`01` / `02` / …）
- `{模式}`：主打模式代号（`jiejie` / `bixia` / `bazong` / `beyond` / `zhiyin` / `fuwang` 等）

示例：`01-jiejie.md`

## 配套文件

- 原始素材笔记：`{序号}-{模式}-notes.md`
- 配图 / 截图：`assets/{序号}-{模式}/`

## 任务清单

每一篇的写作 task 按 `docs/superpowers/plans/2026-04-22-wechat-marketing-execution.md` 里对应 `Task <N>.*` 清单逐条推进。
