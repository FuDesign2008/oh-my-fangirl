# drafts/

公众号文章草稿目录。

## 用途

- 按周撰写的公众号原稿在这里版本控制，**不对外发布**
- 真实素材（对话截图说明、候选标题、修改痕迹）也收纳在这里，便于下一轮复用

## 命名约定

```
YYYY-MM-DD-<mode>-w<N>.md
```

- `YYYY-MM-DD`：计划发布日
- `<mode>`：主打模式代号（`jiejie` / `bixia` / `bazong` / `beyond` / `zhiyin` / `fuwang` 等）
- `w<N>`：本轮连载中的第几周（`w1` / `w2` / …）

示例：`2026-04-29-jiejie-w1.md`

## 配套文件

- 原始素材笔记：`YYYY-MM-DD-<mode>-w<N>-notes.md`
- 配图 / 截图：`assets/<mode>-w<N>/`

## 任务清单

每一篇的写作 task 按 `docs/superpowers/plans/2026-04-22-wechat-marketing-execution.md` 里对应周的 `W<N>.*` 清单逐条推进。
